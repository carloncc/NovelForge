# 《铁皮城堡》宣传文案

## ① 一句话卖点

沙海吞掉了整个世界，最后的人类把自己焊进一座铁皮城堡——而墙外面的沙，正在学着用亲人的声音，叫他们出去。

## ② 三条宣传短句

1. 它不学你说过的话，它学你没说完的那半句。
2. 夜里不能开灯。因为你一亮，沙就知道你在哪儿。
3. 他焊了四十年的墙，从来没人告诉他：这墙是围着我们，还是围着别的东西。

## ③ 世界观简介（100 字）

世界已被无边沙海吞没。最后的幸存者住在铁皮城堡里，用废铁、集装箱和广告牌把自己焊在沙海中央。城外潜伏着行为诡异的生物：模仿人声、复现记忆、让死者回话、让沙丘自行移动、在夜里发光排序。所有人都相信这世界有魔法。人们靠配给的水和以物易物活着，不敢出城，夜里不敢开灯。

（约 108 字，可直接用作 demo 首屏文案）

## ④ 人物表

| 名字 | 身份 | 一句特征 |
| --- | --- | --- |
| 沈岩 | 守夜人（第一人称叙述者） | 九年守着北墙第七块补丁，一慌就无声数数，用铁钉在砖缝里给每一声敲击记账 |
| 老焊 | 焊工，第一批落脚的人 | 焊了四十年铁，说完话必用指节敲两下铁：「铁不骗人。」 |
| 阿禾 | 配水员 | 每次舀水前把铁勺在桶沿敲两下，当，当；勺子永远在手心里转圈 |
| 苏医生 | 据点里唯一懂医的人 | 炭笔指节永远是黑的，从不甩手——「甩出去的水不是我的，擦回来的才是」 |
| 小满 | 在城堡里出生的孩子 | 会唱娘教的歌谣，永远只唱到七，「八个是沙，不是你妈妈」 |

**暗线人物**：老周（六年前独自出城、再没回来的配水员，留下三十七天的声音笔记）；沈岩的父亲（十一年前在北墙外堵风口，隔着铁皮留下最后一句话）。

## ⑤ 建议的 demo 章节（挑 3 章）

### 首选：第一章 墙在敲

**理由**：全篇的钩子章。开头三十秒内给出规则（守夜、数声音、三条禁忌）、给出主角（守夜人沈岩）、给出两名配角（阿禾、小满），并在结尾完成第一次「世界观级惊吓」——敲击声从墙外移到墙内。场景天然分镜：城墙顶 → 楼梯口 → 城墙顶 → 院子仰角，一张背景图就能立住整章。适合做 demo 的开场章。

### 次选：第四章 不能开灯

**理由**：视觉冲击最强的一章，最适合放进宣传片。焊工棚里不发光的灯、墙上自行排列的七扇窗、沙子在手心里像炭一样发亮、铁皮上鼓出的手掌印——全是能直接出图的高概念画面。规则本身（夜里不能开灯）一句话就能让玩家理解并紧张，且结尾悬念是「形状是一个手掌」，截图即卖点。

### 三选：第八章 第九声

**理由**：demo 的收尾爆点。沙海尽头亮起一座「镜子城堡」，七个窗户与配给厅一一对应，第七个是暗的；光一排排往南移动，在离城墙半里地的地方停下。儿童歌谣的「第八声」被接上，第九声却从城堡内部（水塔方向）响起——完美的高潮+钩子结构，适合做 demo 的最后一屏与续作预告。

**不推荐做 demo 的**：第六章「出城的人」信息量最大（沙下埋着第二座城堡、父亲的骨、老周的笔记），但依赖前五章铺垫，独立看会糊；适合放在 demo 的「剧情回顾」或付费章节位置。
