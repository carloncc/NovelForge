## 一、这是什么

《铁皮城堡》讲一座用废铁焊起来的城墙，和墙里墙外的人。
故事是**末世沙漠 + 废土工业**的调子：城墙外是无边沙海，墙里的人靠配给水活着，
守夜人夜里听见墙在敲——三下、停、两下。

宣传 demo 把小说前 8 章做成了**可玩的视觉小说**：有背景、有立绘差分、有配音，
双击就能跑，用来做预告/试玩。

**成品统计**

| 章节 | 8 章（`game\scene\ch1..ch8.txt`） |
| 背景 | 30 张 |
| 立绘差分 | 92 个 |
| 配音 | 612 条 |

## 三、怎么跑起来

> ⚠️ **必须走 `启动游戏.bat`，或者手动起本地服务开 `http://127.0.0.1:8080/`。
> 不要双击 `index.html`。**

原因是 WebGAL 引擎用 `fetch` 加载剧本、立绘和音频，浏览器对 `file://` 协议有同源限制，
直接双击 `index.html` 会**白屏或加载不出素材**（控制台报 CORS / 跨域错误）。
走 `http://127.0.0.1:8080/` 就没有这个问题。

```powershell
# 生成完成后，在成品目录里：
.\启动游戏.bat          # 自动起本地服务并打开浏览器
```

`serve.cjs` 是一个零依赖的 Node 静态服务器，`启动游戏.bat` 会调用它。

## 四、怎么在自己的机器上复现

**完整 runbook 见 [`生成步骤.md`](生成步骤.md)**（38 KB，逐步说明，含每一步的输入/输出/校验）。
概览见 [`生成全部-说明.md`](生成全部-说明.md)。

一键脚本：

| 脚本 | 用途 |
|---|---|
| `生成全部.ps1` | 交互式跑完整条流水线 |
| `生成全部-自动.ps1` | 无人值守跑完整条流水线 |
| `full-run.mts` | Node/TS 版的流水线主控（被上面两个脚本调用） |
| `serve.cjs` | 本地静态服务器（`http://127.0.0.1:8080/`） |
| `启动游戏.bat` | 起服务 + 打开浏览器，玩家的入口 |

复现需要**你自己的**图像/语音生成 API key（原流水线调用付费 API 出图与配音）。
**本仓库里的宣传物料（封面、循环短片、九宫格）不依赖任何 API**，
纯用本机 ffmpeg 合成，命令见 [`宣传物料-说明.md`](宣传物料-说明.md)。
