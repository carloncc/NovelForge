## 2. 选图理由

### 封面底图：`game\background\bg_walltop_day_clear.png`

任务给的首选是 `cg_walltop.png`，实际选了 `bg_walltop_day_clear.png`，理由：

- **它是唯一一张纯"城墙 + 沙海"的景**。`cg_walltop*.png` 系列都是夜景 + 人物群像，画面重心在人物身上，城墙只是背景板。
- **构图适合做封面**：巨大的锈铁城墙从画面左下斜切到右上，太阳在左上，**左上角留出大片干净天空**，正好压标题文字而不压人物。
- **缩略图辨识度高**：暖沙色 vs 冷灰天空的强对比，缩到 320px 宽仍然一眼看清是"墙"和"沙"。
- 无人物 → 不会和后续叠加的人物立绘、标题抢视觉。

备选（都已实地对比过）：`cg_walltop.png`（夜景双人，偏暗）、`cg_walltop_3.png`（夜景三人 + 火盆，信息量最大 → 用作 loop-02 底图）、`cg_walltop_5.png`（白日双人 + 轮胎印，人物居中偏左，裁 16:9 会切到人）。

### 循环短片底图

- `loop-01` → `bg_walltop_day_clear.png`（与封面同源，保持物料一致）
- `loop-02` → `cg_walltop_3.png`（夜景、火盆、三个角色 + 小孩，与 loop-01 的白日空景形成冷暖/有无人的对照）

## 3. 可复现命令

### 3.1 封面 1920×1080

源图 1536×1024（3:2）。1536×864 正好是 16:9，所以**先居中裁掉上下各 80px，再放大到 1920×1080**（lanczos）。
`-compression_level 100 -pred mixed` 是 PNG 无损重压缩，**像素完全不变**，只是把文件从 4.49 MiB 压到 2.72 MiB。

```powershell
& $FF -hide_banner -y -i "game\background\bg_walltop_day_clear.png" `
  -vf "crop=1536:864:0:80,scale=1920:1080:flags=lanczos" `
  -frames:v 1 -compression_level 100 -pred mixed -update 1 "宣传物料\cover-1920x1080.png"
```

> 已实测：把"渲染 → 再压缩"两步写成上面这一条，输出与两步版 **SHA256 完全一致**
> （`CD9B87A5FC6EDF9953AD76377A0E2557CCE3B20293F1EDB7BB22D0BB19F67C38`，2,856,158 B）。

### 3.2 封面 1280×720 JPEG

```powershell
& $FF -hide_banner -y -i "宣传物料\cover-1920x1080.png" `
  -vf "scale=1280:720:flags=lanczos" `
  -frames:v 1 -q:v 3 -pix_fmt yuvj420p -update 1 "宣传物料\cover-1280x720.jpg"
```

`-q:v 3` 即 JPEG 质量 3（mjpeg 的 qscale，2–31，越小越好）。
`-pix_fmt yuvj420p` 是**必须显式指定的**：源图是 `rgb24`，不指定时 ffmpeg 会默认编成 **yuvj444p**（4:4:4）。
4:4:4 JPEG 体积更大、且少数老解码器/部分平台不认；显式降到 4:2:0 后既更小（190,688 B → 153,695 B）又通用。

### 3.3 循环短片 loop-01.mp4（9.60 s）

先裁 16:9 → 放大到 3072×1728（输出尺寸的 2 倍，给 zoompan 留足像素，避免推近时抖动）→ `zoompan` 从 1.00 匀速推到 1.12。
`on` 是输出帧号（0 起），`d=240` = 240 帧 = 9.60 s @ 25 fps。

```powershell
& $FF -hide_banner -y -i "game\background\bg_walltop_day_clear.png" `
  -vf "crop=1536:864:0:80,scale=3072:1728:flags=lanczos,zoompan=z='min(1+0.12*on/239,1.12)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=240:s=1920x1080:fps=25,format=yuv420p" `
  -frames:v 240 -an -c:v libx264 -preset slow -crf 20 -movflags +faststart "宣传物料\loop-01.mp4"
```

### 3.4 循环短片 loop-02.mp4（8.00 s）

同法，换底图、推到 1.14，`d=200` = 200 帧 = 8.00 s。

```powershell
& $FF -hide_banner -y -i "game\background\cg_walltop_3.png" `
  -vf "crop=1536:864:0:80,scale=3072:1728:flags=lanczos,zoompan=z='min(1+0.14*on/199,1.14)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=200:s=1920x1080:fps=25,format=yuv420p" `
  -frames:v 200 -an -c:v libx264 -preset slow -crf 20 -movflags +faststart "宣传物料\loop-02.mp4"
```

**滤镜说明**：本机 6.1.1 上 `zoompan` 可用；`x`/`y` 用 `iw/2-(iw/zoom/2)` 保证始终居中推近，不跑偏。加 `-frames:v N` 与 `d=N` 对齐，避免多出帧。

### 3.5 九宫格预览 contact-sheet.png

布局 4×2，每格 480×270 → 总 1920×540。

- **上排**：4 张背景，裁 16:9 后缩到 480×270。
- **下排**：4 张立绘。立绘是 **1254×1254 的方形、纯绿幕底（实测角像素 `#02FA03`）**，不是透明通道，所以必须抠绿：
  1. `chromakey=0x02FA03:0.32:0.10` 抠掉绿幕；
  2. `geq` 去绿边（despill）：把绿通道钳到 `min(g, max(r,b))`——皮肤/布料本来 `r≥g`，不受影响；只有绿边像素被拉回中性，消除抠图残留的绿边；
  3. `scale=-1:250` 缩到 250px 高，居中叠在**同一张背景的模糊压暗版**上（`boxblur=6:2` + `eq=brightness=-0.20:saturation=0.65`）。
- 8 个单帧用 `concat` 串成序列，再用 **`tile=4x2`** 拼成一张。

```powershell
$key = "chromakey=0x02FA03:0.32:0.10,format=rgba,geq=r='r(X,Y)':g='min(g(X,Y),max(r(X,Y),b(X,Y)))':b='b(X,Y)':a='alpha(X,Y)',scale=-1:250"
$fc = @"
[0:v]split=2[a0][a0b];[a0]crop=1536:864:0:80,scale=480:270,setsar=1,format=yuv420p[t0];[a0b]crop=1536:864:0:80,scale=480:270,boxblur=6:2,eq=brightness=-0.20:saturation=0.65,setsar=1,format=yuv420p[b4];
[1:v]split=2[a1][a1b];[a1]crop=1536:864:0:80,scale=480:270,setsar=1,format=yuv420p[t1];[a1b]crop=1536:864:0:80,scale=480:270,boxblur=6:2,eq=brightness=-0.20:saturation=0.65,setsar=1,format=yuv420p[b5];
[2:v]split=2[a2][a2b];[a2]crop=1536:864:0:80,scale=480:270,setsar=1,format=yuv420p[t2];[a2b]crop=1536:864:0:80,scale=480:270,boxblur=6:2,eq=brightness=-0.20:saturation=0.65,setsar=1,format=yuv420p[b6];
[3:v]split=2[a3][a3b];[a3]crop=1536:864:0:80,scale=480:270,setsar=1,format=yuv420p[t3];[a3b]crop=1536:864:0:80,scale=480:270,boxblur=6:2,eq=brightness=-0.20:saturation=0.65,setsar=1,format=yuv420p[b7];
[4:v]$key[f4];[b4][f4]overlay=(W-w)/2:(H-h)/2,setsar=1,format=yuv420p[t4];
[5:v]$key[f5];[b5][f5]overlay=(W-w)/2:(H-h)/2,setsar=1,format=yuv420p[t5];
[6:v]$key[f6];[b6][f6]overlay=(W-w)/2:(H-h)/2,setsar=1,format=yuv420p[t6];
[7:v]$key[f7];[b7][f7]overlay=(W-w)/2:(H-h)/2,setsar=1,format=yuv420p[t7];
[t0][t1][t2][t3][t4][t5][t6][t7]concat=n=8:v=1:a=0,tile=4x2
"@
& $FF -hide_banner -y `
  -i "game\background\bg_walltop_day_clear.png" -i "game\background\bg_courtyard_dusk_clear.png" `
  -i "game\background\bg_watertower_day_clear.png" -i "game\background\bg_rationhall_morning_clear.png" `
  -i "game\figure\figure_ahe_normal.png" -i "game\figure\figure_laohan_normal.png" `
  -i "game\figure\figure_shenyan_normal.png" -i "game\figure\figure_xiaoman_normal.png" `
  -filter_complex $fc -frames:v 1 -update 1 "宣传物料\contact-sheet.png"
```

上排 4 张背景依次是：城墙沙海（白日）、庭院黄昏、水塔白日、配给厅清晨。
下排 4 个角色依次是：阿禾、老韩、沈砚、小满（均取 `_normal` 基础立绘）。

## 5. 换过写法的滤镜

- **`geq` 去绿边**：ffmpeg **没有**内置 despill 滤镜。这里用 `geq` 的逐像素表达式手工实现
  `g' = min(g, max(r,b))`，效果等价于常见抠像软件的 "despill / 去溢色"。
  注意 `geq` 会重写所有通道，**必须显式带 `a='alpha(X,Y)'` 保留抠像得到的 alpha**，否则透明区会被填实。
- **`tile` 之前必须先 `concat`**：`tile` 吃的是"连续多帧"，不是多路输入。这里把 8 个单帧
  `concat=n=8:v=1:a=0` 成 8 帧序列再 `tile=4x2`。所有分格必须尺寸/像素格式一致，所以每格都补了
  `setsar=1,format=yuv420p`。
- 未使用 `ffprobe`（本机没有），时长/分辨率一律用 `ffmpeg -i` 读。
